# Decision record

**2026-08-21 — v1 locked; 1.0.0rc2 final candidate.** Ship an offline-first Python 3.10–3.12 developer
CLI named `zoracleflux`. The deterministic path checks declared relations from a
versioned transparent registry, exports reviewable tests, and fails closed on
unknown or malformed metadata. Optional model calls, hosted APIs, arbitrary
repository execution, general theorem proving, MCP servers, public marketplace
compatibility, customer-data processing, and production SLA are explicitly
out of scope.

External source is AST-parsed only; no arbitrary `exec`, import, subprocess,
network, credential, or irreversible action is allowed. Antigravity native
support is rejected as unverified; Claude/Codex surfaces are copyable wrappers
around the direct CLI, not claims of tested client integrations.

The final candidate adds `pilot`, a bounded synthetic SQLite ledger. It is a
local rehearsal surface only and is not customer telemetry or validation.
