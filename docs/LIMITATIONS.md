# Limitations

Finite examples can miss defects and do not establish correctness. The
template registry is intentionally narrow; unsupported tags are errors rather
than guesses. External code is parsed, not executed. Timing limits are
cooperative and are not an OS sandbox. Mutation testing covers five explicit
trusted fixture mutants, not arbitrary repositories. There is no hosted service,
authentication, SLA, telemetry, package-signing key, or customer-data retention
contract. Customer interviews, willingness-to-pay, and production uptime are
not yet validated.
